# Engineering Standards

[`engineering-standards.md`](engineering-standards.md) is the normative policy
document for this repository. Its RFC 2119 requirements (MUST, SHOULD, and
MAY) govern GitOps changes, workload manifests, secrets, observability,
reliability, testing, documentation, and review.

An exception to a normative requirement MUST be documented and name its owner,
expiry date, and compensating control. Renew or remove the exception before its
expiry.

> 任何标准例外必须写明负责人、到期日期和补偿性控制。
